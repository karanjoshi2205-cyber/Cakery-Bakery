# 🍰 Cakery Bakery

Cakery Bakery is a modern and responsive bakery website designed with a clean and attractive user interface. It showcases different bakery products and provides a smooth browsing experience across desktop and mobile devices.

## ✨ Features

- Responsive and mobile-friendly design
- Attractive homepage and hero section
- Bakery categories and featured products
- Interactive navigation menu
- Hover effects and smooth UI transitions
- Best-selling food section
- Newsletter subscription section
- App promotion section
- Contact and footer section

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Google Fonts
- Font Awesome

## 🎯 Purpose

This project was created to practice and improve front-end web development skills, including responsive layouts, CSS styling, Flexbox, media queries, hover effects, and basic JavaScript DOM manipulation.
